
# 💸 AI Expense Tracker

A secure and scalable expense tracking application with AI-driven insights, real-time analytics, and interactive dashboards to help users manage and analyze their spending.

---

## 🚀 Features
- Secure user authentication with JWT
- Expense tracking with category-wise analysis
- AI-powered insights for spending patterns
- Monthly and time-series reports
- Interactive dashboards and charts
- Role-aware protected APIs

---

## 🛠️ Tech Stack
**Frontend**
- React.js
- Charting Libraries

**Backend**
- Node.js
- Express.js

**Database**
- MongoDB

**AI Integration**
- OpenAI API

**Authentication & Security**
- JWT
- bcrypt

---

## 📊 How It Works
1. Users log in securely using JWT authentication.
2. Expenses are stored and processed using optimized MongoDB schemas.
3. AI analyzes spending behavior and provides insights.
4. Dashboards display real-time and monthly analytics.
5. Secure APIs ensure data integrity and access control.
